# ing8100-reproductibility-project

## Data

This dataset was choosen because it has a CC0 liscense allowing us to work 
with them. They come from collaborators: Alexandre D'Astous, PhD candidate 
at Neuropoly, Polytechnique Montreal and Julien Cohen-Adad, Professor at 
Polytechnique Montraal, co-director from Neuropoly. It was taken from 
OpenNeuro: https://openneuro.org/datasets/ds007067/versions/4.0.0.

This data were acquired in the spinal cord and we want to do a shimming 
simulation using the fielmap data in order to compare two methods: volume 
slice shimming and slice-wise shimming. This dataset is revelevant for 
ING8100 beccause it's an open source dataset with a complex structure 
already organized according to the BIDS format.
