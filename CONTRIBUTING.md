# Contributing Guidelines

Contributions are welcome, whether they involve bug reports, 
documentation improvements, new features, or code enhancements.

## Reporting Issues

If you encounter a bug or have a suggestion for improvement, please open an issue on GitHub.

When reporting a bug, include:

- A clear description of the problem.
- Steps to reproduce the issue.
- Expected behavior.
- Relevant error messages.
- Information about your environment, including Python and package versions when applicable.

## Contributing Code

To contribute code, follow these steps:

- Fork the repository.
- Create a new branch for your changes.
- Commit your changes with a clear and descriptive commit message.
- Push your branch to your fork.
- Open a pull request against the main repository.

## Code Guidelines

Please follow these guidelines when contributing code:

- Write clear, readable, and maintainable code.
- Follow the existing project structure and coding conventions.
- Use descriptive variable and function names.
- Add comments or docstrings when necessary.
- Update the documentation when introducing new features or changing existing behavior.
- Avoid introducing unnecessary dependencies.

## Pull Requests

Pull requests should:

- Have a clear and descriptive title.
- Explain the purpose of the changes.
- Reference related issues when applicable.

Please keep pull requests focused on a single feature, bug fix, or improvement whenever possible.

## Questions

If you have questions about contributing, please open a GitHub issue.

Thank you for helping to improve this project!
